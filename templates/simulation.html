What is real here. Raising an incident calls the same engine method the dispatch board calls: the same nearest-first ranking, the same Web Push notification, the same {{ settings.offer_timeout }}-second countdown, up to {{ settings.max_offers }} officers. If you have a real officer on duty with a phone, that phone rings. Incidents raised here are flagged is_simulated and excluded from the dispatch board's average response time, and “Purge” removes them. Distances are straight-line, as the engine's own ranking is.
